# SANIVA Privacy Policy

Effective: 21 August 2026

SANIVA processes storage information and selected files entirely on the Mac where it is running. It does not create an account, connect to an analytics or advertising service, upload filenames or file contents, sell data, or share data with a third party.

Duplicate scanning reads selected local files only to calculate comparison hashes. Hashes and scan results remain in memory and are not transmitted or retained after the app closes. Moving duplicates to Trash uses the standard recoverable macOS Trash mechanism.

Safe Cleanup accesses only the current user’s Trash and app-cache folders. The optional all-user scan runs a clearly disclosed, administrator-approved, read-only size command. Weekly reminders use Apple’s local notification system.

SANIVA has no network service. Future versions that introduce data collection or networking must update this policy before release.
